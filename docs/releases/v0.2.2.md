LeanFlip v0.2.2 换上了新图标。

![LeanFlip 新图标](https://github.com/Ricardo121380/LeanFlip/raw/v0.2.2/crates/app/icons/128x128@2x.png)

## 新图标

- App 图标、侧栏顶部和网页标签统一为同一个图形：一个亮的 L，加上把它翻过来、变暗的 L。底色是界面的灰靛主色。
- macOS 菜单栏改用单色图标，会随菜单栏的深浅色自动变黑或变白。Linux 托盘仍使用 App 图标。

## 安装

- Homebrew（macOS Apple Silicon；命令行也支持 Linux x86_64）：

  ```sh
  brew tap ricardo121380/leanflip https://github.com/Ricardo121380/LeanFlip.git
  brew install --cask ricardo121380/leanflip/leanflip-app
  brew install --cask ricardo121380/leanflip/leanflip
  ```

- npm：`npm install -g leanflip`。从这个版本起，npm 包随 GitHub 发布自动更新。
- 直接下载：

| 平台 | 桌面 App | 命令行与 TUI |
| --- | --- | --- |
| macOS Apple Silicon（M 系列） | `leanflip_0.2.2_macos-arm64.dmg` | `leanflip_0.2.2_macos-arm64.tar.gz` |
| Linux x86_64（Ubuntu 24.04 构建） | `leanflip_0.2.2_linux-x64.deb` | `leanflip_0.2.2_linux-x64.tar.gz` |

从 0.2.x 升级：退出 App 后覆盖安装即可，数据不受影响。macOS 的程序坞可能还会显示旧图标，重新打开 App 后更新。

**macOS 首次打开：** App 和命令行没有 Apple 签名与公证，第一次运行会被系统拦下。App 在提示后进入“系统设置 → 隐私与安全性”，点“仍要打开”；命令行在解压目录执行 `xattr -d com.apple.quarantine leanflip`。

已知限制同 [v0.2.1](https://github.com/Ricardo121380/LeanFlip/releases/tag/v0.2.1)。
