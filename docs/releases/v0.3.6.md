LeanFlip v0.3.6 修复 NewAPI / sub2api 的额度查询，并新增 Krill 账户套餐额度。

## 额度查询修复

- NewAPI 使用正确的 `/api/usage/token/` 路径，避免因末尾斜杠触发重定向而查询失败。
- NewAPI 和 sub2api 支持部署在路径前缀下的站点。优先查询根路径；接口不存在或格式不匹配时，再尝试卡片地址中的前缀。识别窗口列出实际请求地址。
- 查询仍只访问卡片所在站点，不跟随重定向；限流、服务器错误和网络错误不会触发同平台的路径重试。

## Krill 账户套餐

- 在供应商编辑器的“额度查询”中选择 Krill，填写独立的 Krill 登录 JWT，即可预览额度并设置自动刷新。
- 使用官网的 `/api/subscription`，分别显示有效金额套餐、按次套餐和账户余额；日套餐包含结转额度，冻结或到期套餐不计入。
- 多张卡使用同一 JWT 时合并为一个额度来源。JWT 失效或无权限时提示更新。
- JWT 随卡片保存在本机私有供应商库中，读取时向前端返回占位符；不会写入模型配置、额度缓存或错误详情。复制卡片不复制隐藏的 JWT，切换到其他额度平台或关闭查询并保存会移除该卡的 JWT。
- JWT 来自登录官网后浏览器 Local Storage 的 `krill_jwt`；模型 API Key 不能代替。凭据未额外加密，包含供应商库的备份也应按账号凭据保管。详细步骤见[使用手册](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.6/docs/guide.md#额度)。

## 验证与升级

本地已通过 412 项 Rust 测试、252 项前端测试、TypeScript 类型检查、Clippy 和前端构建。Krill 的字段与官网前端核对，并通过模拟 HTTP 和交互回归测试；尚未用真实登录 JWT 做线上账户验证。

退出 App 后覆盖安装即可，现有供应商、场景、账号和客户端配置继续使用。发布附件由 GitHub Actions 构建，并附带 `SHA256SUMS`。

- npm：`npm install -g leanflip@0.3.6`。通过 npm 安装器管理桌面 App 的用户，退出 App 后执行 `leanflip-app install --replace`；自定义安装目录时继续使用原来的 `--app-dir`。
- Homebrew：`brew update`，再升级已安装的 `ricardo121380/leanflip/leanflip` 或 `ricardo121380/leanflip/leanflip-app` Cask。
- 下载附件：macOS Apple Silicon 的 `.dmg` 与 CLI `.tar.gz`，以及 Linux x86_64 的 `.deb` 与 CLI `.tar.gz`。

macOS App 和 CLI 仍未做 Apple Developer ID 签名与公证；首次运行说明见 [README](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.6/README.md#安装)。
