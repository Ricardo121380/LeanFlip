LeanFlip v0.3.1 调整首页的连通检测入口，让检测操作与完整结果集中在光路视图。

## 首页

- 清单视图移除“测连通”按钮，保留供应商状态和快捷切换。
- 光路视图继续提供“测连通”，并显示各地址的连通情况和延迟。
- 各 Agent 供应商管理页的连通检测保持原有行为。

此前清单只展示当前使用中的供应商检测结果，候选供应商虽然已检测却不显示结果，使用官方登录时容易被误认为按钮没有响应。

## 升级

从 0.3.0 升级时，退出 App 后覆盖安装即可；供应商、账号和客户端配置保持原样。已有的官方供应商卡片不会去重或合并。

- npm：`npm install -g leanflip@0.3.1`。通过 npm 安装器管理桌面 App 的用户，退出 App 后执行 `leanflip-app install --replace`，自定义安装目录时继续使用原来的 `--app-dir`。
- Homebrew：`brew update`，再升级已安装的 `ricardo121380/leanflip/leanflip` 或 `ricardo121380/leanflip/leanflip-app` Cask。
- 下载附件：macOS Apple Silicon 的 `.dmg` 与 CLI `.tar.gz`，以及 Linux x86_64 的 `.deb` 与 CLI `.tar.gz`。SHA256 校验值见 `SHA256SUMS`。

macOS App 和 CLI 仍未做 Apple Developer ID 签名与公证；首次运行说明见 [README](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.1/README.md#安装)。

## 已知界面问题

- 通用配置较长时，保存失败的错误提示可能位于滚动区域下方，需要滚动才能看到；外部修改保护仍会阻止覆盖文件。
- 统计时间线首行的提示框可能被裁切。这两项不包含在本次修复中。
