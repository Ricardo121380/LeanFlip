LeanFlip v0.3.2 修复通用配置错误提示与统计时间线提示的可见性，并整理所有 Agent 的配置编辑界面。

## 通用配置

- JSON 格式错误、外部修改冲突和保存失败现在显示在固定底栏，长配置无需滚到底部才能看到原因。
- JSON 语法错误与“顶层必须是对象”分别提示；保存失败时保留编辑内容。
- 所有 Agent 使用统一的快捷设置与 JSON 编辑形式，不再把任意布尔字段自动生成为原始字段名开关。
- 快捷设置区分默认、开启、关闭和自定义值；自定义列表及部分设置以横杠显示，恢复默认只清除对应覆盖项。
- 保存位置按需展开，并说明实际写回的客户端文件格式。连接字段保护与外部修改校验继续生效。

## 供应商与统计

- 供应商编辑器完全隐藏内部 ID，新增和复制时自动生成唯一标识；已有供应商标识保持不变，官方渠道不去重。
- 时间线提示不再被滚动容器裁切，并自动避让窗口边缘。
- 窄窗口中，键盘聚焦触发横向滚动时仍保留提示；失焦、Escape 或点击后正常关闭。

## 验证

完成 TypeScript 类型检查、164 项前端测试及本机隔离 App 验证；逐一检查 10 种 Agent 的通用配置保存与文件内容，覆盖供应商切换、窄窗口统计、错误反馈和加密备份恢复。测试使用独立配置，未改动真实客户端配置。

## 升级

从 0.3.1 升级时，退出 App 后覆盖安装即可；供应商、账号和客户端配置保持原样。

- npm：`npm install -g leanflip@0.3.2`。通过 npm 安装器管理桌面 App 的用户，退出 App 后执行 `leanflip-app install --replace`；自定义安装目录时继续使用原来的 `--app-dir`。
- Homebrew：`brew update`，再升级已安装的 `ricardo121380/leanflip/leanflip` 或 `ricardo121380/leanflip/leanflip-app` Cask。
- 下载附件：macOS Apple Silicon 的 `.dmg` 与 CLI `.tar.gz`，以及 Linux x86_64 的 `.deb` 与 CLI `.tar.gz`。SHA256 校验值见 `SHA256SUMS`。

macOS App 和 CLI 仍未做 Apple Developer ID 签名与公证；首次运行说明见 [README](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.2/README.md#安装)。
