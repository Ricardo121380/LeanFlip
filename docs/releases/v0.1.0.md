CC Switch Lite 的首个版本，同时提供桌面 App 和独立命令行 `ccsl`。两者共用本地供应商库，直接管理客户端配置，无需运行本地代理。

## 主要功能

- 管理 Claude Code、Codex、Gemini CLI、Grok Build、Claude Desktop，以及 OpenCode、OpenClaw、Hermes、Pi、MCode 的供应商配置。
- 桌面端支持供应商搜索、配置编辑、导入预览、托管 Codex 账号；编辑和设置草稿在离开前会提示保存。
- 终端直接运行 `ccsl` 进入中文交互菜单：方向键选择，输入文字筛选，回车确认，Esc 返回。执行前展示目标和配置路径。
- 保留完整命令模式及稳定 JSON 输出；`--lang en` 切换英文，`--home` 可指定隔离目录。
- App 与 CLI 共用跨进程写锁、首次写入备份和中断恢复机制。

## 下载与安装

| 平台 | 桌面 App | CLI |
| --- | --- | --- |
| macOS Apple Silicon（M 系列） | `ccswitch-lite_0.1.0_macos-arm64.dmg` | `ccsl_0.1.0_macos-arm64.tar.gz` |
| Linux x86_64（Ubuntu 24.04 构建） | `ccswitch-lite_0.1.0_linux-x64.deb` | `ccsl_0.1.0_linux-x64.tar.gz` |

macOS：打开 DMG，将 App 拖入「应用程序」。本版未配置 Apple Developer ID 签名与公证，macOS 可能阻止首次打开；确认下载来自本仓库后，可在「系统设置 → 隐私与安全性」中允许打开。

Linux 桌面端：在下载目录执行 `sudo apt install ./ccswitch-lite_0.1.0_linux-x64.deb`，由包管理器安装依赖。其他发行版尚未验证。

CLI：解压对应平台的 `.tar.gz`，运行 `./ccsl` 即可；需要全局调用时，将 `ccsl` 放入已有的 PATH 目录。无需安装 Node.js、Rust 或桌面 App。

```sh
./ccsl                     # 打开交互菜单
./ccsl menu codex           # 选择 Codex 供应商
./ccsl status              # 查看配置状态
./ccsl --lang en --help     # 英文命令帮助
./ccsl status --json        # 脚本输出
```

下载附件后，可用 `shasum -a 256 <文件名>`（macOS）或 `sha256sum <文件名>`（Linux）与 `SHA256SUMS` 中的值比对。

## 使用说明

- App 与 CLI 默认共用 `~/.cc-switch-lite/`；切换或启用供应商会修改对应工具的配置文件。
- 已有配置可通过 App 导入页或 CLI 的「导入当前配置」导入；从 cc-switch 导入只会写入本应用的供应商库。
- 本版提供上述两个平台的原生构建；未提供 Windows、Intel Mac 或 Linux ARM 安装包。
- 自动检查覆盖前端类型与测试、Rust 测试和 Clippy、CLI 真实伪终端交互及桌面打包；外部账号登录需要用户在自己的环境中完成。
