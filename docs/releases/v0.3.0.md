LeanFlip v0.3.0 新增多 Agent 通用配置编辑器，并修复供应商状态、重复导入、用量统计与界面交互问题。

## 通用配置编辑器

- Claude Code、Codex、Gemini CLI、Grok Build、Claude Desktop、OpenCode、OpenClaw、Hermes、Pi 和 MCode 都可以从工具页编辑通用配置。
- 快捷开关与 JSON 共用一份草稿，保存为客户端原生格式。Claude、Codex、Gemini 和 OpenCode 提供预置选项；其他 Agent 可编辑已有布尔选项和 JSON。
- 通用配置保留供应商连接、凭据及路由字段，文件被外部修改时拒绝覆盖。保存后的偏好在切换供应商时保留；部分选项需要重启 Agent，项目配置或启动参数可能覆盖用户级设置。
- 常用设置隐藏内部 ID，创建时自动生成；需要查看或设置时可展开完整配置中的高级区域。

## 供应商与配置可靠性

- 修改模型、推理强度或未启用的供应商表后，不再把仍在使用的供应商误判为未选择；真正的连接或鉴权变化仍会提示配置偏差。
- “从当前配置导入”可以保存新的配置快照；相同配置已存在时不重复建卡、不改变当前选择，既有卡片不会被删除或合并。
- 修复未保存草稿的导航保护、Codex 登录引用保存、无效配置与目录校验，以及保存和启用失败时的回滚。
- 修复 CLI 表单或菜单中按 Ctrl+C 后终端可能保持原始输入模式的问题。

## 用量统计与界面

- 修复流式用量更新被漏计、复制会话历史被重复计数的问题。
- Codex 会话中的官方路由不再因对应多张卡片而丢失归属；没有足够证据区分卡片时明确显示“官方 OpenAI（未区分卡片）”。
- 旧 Codex 汇总仅在可用原始记录的全部计数与汇总相符时重新归属，总量不变；原始日志缺失的汇总保持原样。
- 前一比较周期数据不足时停止显示增长百分比；窄窗口中的表格可以独立横向滚动。
- 时间线保留短时段的真实比例，并提供完整时段列表；已删除的供应商不可再从历史记录恢复。
- 光路中的同名记录共用名称、保留独立选择按钮，相同地址的连通检测只发送一次请求；不同路径分别检测。
- 修复模型名解析和无障碍重复文字，设置页可查看应用版本。

## 升级

从 0.2.x 升级时退出 App 后覆盖安装，供应商、账号与客户端配置保留。首次打开统计页可能需要重扫已有用量日志，后续恢复增量扫描。

- npm：`npm install -g leanflip@0.3.0`。用 npm 安装器管理桌面 App 的用户，退出 App 后执行 `leanflip-app install --replace`；自定义安装目录时继续使用原来的 `--app-dir`。
- Homebrew：`brew update`，再升级已安装的 `ricardo121380/leanflip/leanflip` 或 `ricardo121380/leanflip/leanflip-app` Cask。
- 直接下载：

| 平台 | 桌面 App | 命令行与 TUI |
| --- | --- | --- |
| macOS Apple Silicon（M 系列） | `leanflip_0.3.0_macos-arm64.dmg` | `leanflip_0.3.0_macos-arm64.tar.gz` |
| Linux x86_64（Ubuntu 24.04 构建） | `leanflip_0.3.0_linux-x64.deb` | `leanflip_0.3.0_linux-x64.tar.gz` |

所有附件的 SHA256 校验值见 `SHA256SUMS`。npm 安装器和 Homebrew 使用相同的原生发布包。

macOS App 和 CLI 仍未做 Apple Developer ID 签名与公证；首次运行可能需要在系统“隐私与安全性”中手动允许。安装与升级说明见 [README](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.0/README.md#安装)。
