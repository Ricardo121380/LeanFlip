# LeanFlip v0.4.1

修复凭据命令授权、OpenCode 包加载确认、配置写入恢复、CC Switch 导入和 Windows 旧数据目录兼容问题，并为常见错误提供操作指引。

## 授权与连接配置

- 凭据命令的本机授权现在同时绑定目标地址和相关连接配置。修改 Codex 目标地址、请求头或查询参数，以及 Claude 的连接地址后，需要重新确认（#55）。
- OpenCode 的 `npm` / `package` 引用，包括 V1/V2 配置和模型级覆盖，写入客户端前需要本机授权。编辑器和 CLI 会展示包引用及目标地址（#56）。
- 旧版未绑定目标地址的授权不再沿用。GUI 可编辑卡片并保存以重新审核；CLI 先保存卡片，再运行 `leanflip provider trust-commands <tool> <id>`，按预览完成授权后启用。

## 写入与导入恢复

- 并存式工具的卡片新增、更新、删除与客户端配置写入纳入同一次恢复记录，避免卡片库写入失败后丢失恢复依据（#60）。
- 从本机 CC Switch 目录导入账号和卡片时，共同记录恢复目标。重试先完成上次中断的导入，保留去重行为和源文件（#61）。
- 开始写入前中断会放弃未完成操作；开始写入后中断会保留记录，供重试、启动或 `leanflip recover` 继续完成。报错不表示立即撤销；如同一卡片已被外部修改，恢复会停止并保留记录，避免覆盖新编辑。

## 使用体验与兼容

- 文件读写、配置冲突和部分 Codex OAuth 错误按界面语言显示具体恢复建议；写操作错误提示提供“复制详情”以保留诊断信息（#59）。
- Windows 若只有旧 `.cc-switch-lite` 数据目录，继续使用该目录，避免自动改名后旧版本无法访问。新安装仍使用 `.leanflip`，macOS/Linux 保留原有迁移及兼容链接行为（#62）。

编辑器底部遮挡报告 #58 尚未复现，仍在收集截图、操作系统和缩放信息，本版不宣称修复该问题。

继续提供 macOS Apple Silicon、Linux x64、Windows x64 桌面与 CLI 安装包，以及 Homebrew/npm 安装入口。附件校验值见 `SHA256SUMS`。
