# LeanFlip v0.4.3

新增首次使用向导，帮助新用户了解 LeanFlip，并选择从 CC Switch、AI Toolbox 或 Superba 导入 Provider 配置。

## 首次使用向导

- 新安装首次启动时自动展示“认识 LeanFlip → 导入 Provider → 首次切换说明”三步向导，支持中文和英文。
- 跳过、关闭或完成后记住状态；已有安装不自动弹出，也可以在“设置 → 使用向导”中重新打开。
- 支持键盘操作、步骤焦点、关闭后返回入口，以及窄窗口下滚动正文和固定底部操作。

## 按需导入 Provider

- CC Switch：支持现有数据库和旧版 JSON 配置，复用工具映射与兼容性检查。
- AI Toolbox：支持 SQLite JSON/JSONB 中 Claude Code、Claude Desktop、Codex 和 Gemini CLI 的独立 Provider 记录。
- Superba：支持 Codex API Provider，保留主地址、模型、推理强度、速度档位及全局上下文设置；内置 Krill 线路使用同一线路的 API Key 端点。
- 自动查找默认数据目录，也可以指定目录；扫描后逐项选择，导入完成可继续选择其他来源。
- 缺少可读取 API Key 的条目允许手动补填；依赖来源应用网关、登录态、手动 PAT 或其他不兼容配置的条目会显示跳过原因。向导不迁移账号登录、自动认证、备用线路或额外公共配置，具体范围见 `docs/onboarding.md`。

## 配置保护

- 扫描只读来源数据，预览不向前端返回已有密钥或完整配置；确认时使用用户预览过的后端快照。
- 只添加选中的 LeanFlip Provider 卡片，重复 ID 跳过、不覆盖现有项；不会自动切换供应商或修改客户端配置。
- 不读取系统钥匙串或环境变量引用，不继承来源配置的命令信任；导入期间阻止关闭和切换来源，失败后可以重试。

继续提供 macOS Apple Silicon、Linux x64、Windows x64 桌面与 CLI 安装包，以及 Homebrew/npm 安装入口。附件校验值见 `SHA256SUMS`。macOS 程序仍未做 Developer ID 签名及公证。
