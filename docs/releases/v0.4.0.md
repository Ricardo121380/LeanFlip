# LeanFlip v0.4.0

新增 Windows 10 / 11 x64 桌面端、原生命令行和全屏 TUI，与 macOS、Linux 共用同一套配置管理功能。

## Windows 安装

- 桌面端：下载 `leanflip_0.4.0_windows-x64-setup.exe`。安装器支持简体中文和英文，默认安装到当前用户的 `%LOCALAPPDATA%\LeanFlip`，缺少 WebView2 时会下载运行时。
- 命令行与 TUI：解压 `leanflip_0.4.0_windows-x64.zip`，在 PowerShell / Windows Terminal 中运行 `leanflip.exe` 或 `leanflip.exe tui`。
- npm（Node.js 20+）：`npm install -g leanflip`。运行 `leanflip` 下载并校验原生 CLI；`leanflip-app install` 打开桌面安装向导。
- 数据保存在 `%USERPROFILE%\.leanflip`。升级和卸载程序保留供应商、账号和备份。

Windows 安装包尚未使用代码签名证书，首次运行可能显示 SmartScreen 提示；请从本仓库 Release 下载，并核对附件的 `SHA256SUMS`。本版不提供 Windows ARM64 或 32 位原生构建。

## 开发与分发

- Windows CI 覆盖 Rust 工作区测试、Clippy、前端测试、NSIS 打包，以及安装、窗口启动、真实 WebView2 IPC 切换与配置回读、覆盖安装和卸载检查。
- npm 安装器支持 Windows 原生 `.exe`、ZIP 下载与校验，并保留 macOS / Linux 分发。
- `pnpm dev:mock` 可直接在 PowerShell、cmd 和 Unix shell 中使用。

macOS Apple Silicon 的 DMG、Linux x64 的 DEB，以及各平台 CLI 与 npm 安装入口继续提供。全部附件均纳入 `SHA256SUMS`。
