# LeanFlip v0.4.4

AI Toolbox 和 Superba 的 Provider 导入现已加入“数据与迁移”，已有用户可以直接迁移配置，无需重新打开首次使用向导。

## 数据与迁移

- 在“本机数据目录”中选择 CC Switch、AI Toolbox 或 Superba。
- AI Toolbox、Superba 支持自动检测默认目录、手动指定目录、扫描预览、逐项选择，以及补填缺失的 API Key。
- CC Switch 保留现有供应商和托管账号迁移流程；文件导入、加密备份与恢复继续使用原有入口。
- 向导与迁移页共用 Provider 导入组件，向导完成页也会提示日常迁移入口。

## 操作与配置保护

- 来源或目录变更后，旧预览立即失效；离开 AI Toolbox 或 Superba 导入页时清理未提交的密钥和后台预览。
- 扫描、导入期间禁止切换来源与迁移页签。缺失密钥、重复配置和不兼容条目仍使用原有检查。
- 只读取来源配置，确认后添加选中的 LeanFlip 卡片；不覆盖已有卡片，不自动切换，也不修改客户端配置。

## 验证与分发

相关前端回归 23 项及 TypeScript 检查通过。Ego Lite 模拟后端交互与实际截图检查覆盖三个来源入口、AI Toolbox 单项导入、Superba 密钥补填，以及 1380×745 和 860×560 视口。浏览器验证不等同于原生平台或真实来源数据验收。

继续提供 macOS Apple Silicon、Linux x64、Windows x64 桌面与 CLI 安装包，以及 Homebrew/npm 安装入口。附件校验值见 `SHA256SUMS`。macOS 程序仍未做 Developer ID 签名及公证；Windows 安装包未签名，原生 CLI/TUI 需要 Visual C++ v14 x64 运行库。
