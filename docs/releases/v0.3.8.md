LeanFlip v0.3.8 将额度平台选择改为基于 Base URL 的自动适配，并修复额度识别窗口重复查询的问题。

## 额度自动适配

- 删除供应商编辑器中的平台类型下拉框，保留“启用额度查询”、自动刷新间隔和对应的账户设置。
- 已知 Krill 官方接口地址直接显示官网登录入口；其他站点查询时自动识别 NewAPI / sub2api 并应用结果。
- 编辑 Base URL 后，旧地址的识别结果失效；进行中的 Krill 登录会取消，迟到的登录结果不会应用到新地址。
- 关闭再开启额度查询保留账户连接。已有独立用户访问令牌、Krill 登录凭据及模型 API Key 继续分开处理。
- 尚未连接 Krill 账户时也可保存卡片，查询时再引导登录；Krill 的模型 Key 不会被用于官网账户额度查询。

## 查询稳定性

- 修复额度探测写入缓存后，被文件监听刷新再次触发的循环查询；完成探测后保持结果，只有用户主动重试才再次探测。
- 补充自动适配、地址变更、凭据保留、取消登录和查询刷新回归测试。

## 已知限制

macOS 内嵌 Krill 登录窗口暂不支持 LinuxDO 通行密钥，本版本只增加入口说明，尚未打通通行密钥登录。可使用 LinuxDO 密码或 Krill 邮箱验证码连接；已连接的账户仍可查询额度。

额度与登录交互通过模拟接口和 Ego Lite 浏览器回归检查；本次未执行真实通行密钥登录端到端验证。

## 升级

退出 App 后覆盖安装，现有供应商、场景、账号和客户端配置继续使用。附件由 GitHub Actions 构建，附带 `SHA256SUMS`。

- npm：`npm install -g leanflip@0.3.8`。通过 npm 管理桌面 App 的用户，退出 App 后执行 `leanflip-app install --replace`；自定义安装目录时继续使用原来的 `--app-dir`。
- Homebrew：`brew update`，再升级已安装的 `ricardo121380/leanflip/leanflip` 或 `ricardo121380/leanflip/leanflip-app` Cask。
- 附件：macOS Apple Silicon `.dmg` 与 CLI `.tar.gz`；Linux x86_64 `.deb` 与 CLI `.tar.gz`。

macOS App 和 CLI 尚未做 Apple Developer ID 签名与公证；首次运行说明见 [README](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.8/README.md#安装)。
