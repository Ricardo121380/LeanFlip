LeanFlip v0.3.7 支持独立的账户余额查询和 Krill 官网登录，并在供应商列表直接显示额度。

## 账户余额与平台识别

- NewAPI / sub2api 可单独填写用户访问令牌查询账户余额，模型 API Key 保持独立。兼容需要 NewAPI 用户 ID 的站点。
- 修正 NewAPI “不限”的含义：它只表示模型 Key 未设限。接口未提供账户余额时显示“余额未提供”，不再误报无限余额。
- 刷新时自动识别并记住 NewAPI / sub2api 平台；编辑器查询成功后自动应用识别结果。未开启自动刷新时，打开页面仍只读本机缓存。
- 供应商列表新增额度、更新时间、错误提示和刷新入口，支持逐个或整页刷新。

## Krill 官网登录

- 点击“登录 Krill”后，在独立的官网窗口完成登录，LeanFlip 自动验证并预览套餐额度；保存卡片后生效，无需手动复制 JWT。
- 支持取消与重新登录；保留已有 Krill 配置。登录凭据在后端处理，未保存的登录引用仅在当前进程内短期有效。
- 用户访问令牌和 Krill 凭据保存在本机私有供应商库，读取时脱敏，不写入模型客户端配置、额度缓存或错误详情；未额外加密，备份仍需按账号凭据保管。

使用方式详见[额度手册](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.7/docs/guide.md#额度)。账户接口与 Krill 登录流程已通过模拟接口及交互回归测试；尚未使用真实用户访问令牌或完成真实 Krill 登录做端到端验证，站点的登录策略和凭据权限仍可能影响使用。

## 升级

退出 App 后覆盖安装，现有供应商、场景、账号和客户端配置继续使用。附件由 GitHub Actions 构建，附带 `SHA256SUMS`。

- npm：`npm install -g leanflip@0.3.7`。通过 npm 管理桌面 App 的用户，退出 App 后执行 `leanflip-app install --replace`；自定义安装目录时继续使用原来的 `--app-dir`。
- Homebrew：`brew update`，再升级已安装的 `ricardo121380/leanflip/leanflip` 或 `ricardo121380/leanflip/leanflip-app` Cask。
- 附件：macOS Apple Silicon `.dmg` 与 CLI `.tar.gz`；Linux x86_64 `.deb` 与 CLI `.tar.gz`。

macOS App 和 CLI 尚未做 Apple Developer ID 签名与公证；首次运行说明见 [README](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.7/README.md#安装)。
