LeanFlip（简切）的第一个正式版本。它把 Claude Code、Codex、Gemini CLI、OpenCode 等 AI 编程工具的供应商配置保存在本地，切换时直接写进工具读取的配置文件，不运行本地代理。桌面 App、命令行 `leanflip` 和全屏 TUI 共用同一份数据。

![LeanFlip 首页](https://github.com/Ricardo121380/LeanFlip/raw/v0.2.0/docs/images/home.png)

## 新内容

- **首页**：每个工具一句话，例如“Claude Code 正在用 Kimi”。点供应商名就地展开其他选项，选中即切换，提示里可以一键切回。右上角可换成“光路”视图，看每个工具连到哪个服务端点。
- **统计**：读取各工具留在本机的会话记录，按天显示 token 用量、缓存命中率和每个供应商的用量；时间线记录每段时间用的供应商，点过去的一段即可切回。只读取时间、模型、供应商和 token 数，不读对话内容，也不上传。
- **供应商编辑器**：从预设或空白配置开始；可以测连通、获取模型列表、检查模型是否可用。
- **命令面板**：`⌘K`（Windows / Linux 为 `Ctrl+K`）搜索并切换任意工具的供应商。
- **命令行与 TUI**：新的配色、状态符号和菜单分组；`leanflip tui` 打开全屏工作台。
- **从 CC Switch 迁移**：App、`leanflip import local` 和 TUI 都能检测本机 CC Switch 数据，先预览再迁入，不会修改它的文件。
- **加密备份**：用密码加密导出供应商、托管账号和偏好，在另一台设备上恢复。

## 下载

| 平台 | 桌面 App | 命令行与 TUI |
| --- | --- | --- |
| macOS Apple Silicon（M 系列） | `leanflip_0.2.0_macos-arm64.dmg` | `leanflip_0.2.0_macos-arm64.tar.gz` |
| Linux x86_64（Ubuntu 24.04 构建） | `leanflip_0.2.0_linux-x64.deb` | `leanflip_0.2.0_linux-x64.tar.gz` |

- macOS：打开 `.dmg`，把 `LeanFlip.app` 拖入“应用程序”。
- Linux：在下载目录执行 `sudo apt install ./leanflip_0.2.0_linux-x64.deb`。其他发行版尚未验证。
- 命令行：解压 `.tar.gz`，运行 `./leanflip`；不需要 Node.js 或桌面 App。
- 校验：`shasum -a 256 -c SHA256SUMS --ignore-missing`（Linux 用 `sha256sum`）。

**macOS 首次打开：** App 和命令行没有 Apple 签名与公证，第一次运行会被系统拦下。App 在提示后进入“系统设置 → 隐私与安全性”，点“仍要打开”；命令行在解压目录执行 `xattr -d com.apple.quarantine leanflip`。

## 从 0.1.x 升级

- 数据目录会在首次使用时自动迁移到 `~/.leanflip/`，供应商、托管账号和设置都会保留。
- 新版 App 和命令使用新名称，不会替换旧版。确认新版正常后，手动删除旧版 App 和旧命令。
- 开机自启需要在新 App 的设置里重新打开。

## 已知限制

- 统计页里 Hermes、OpenClaw、Pi 和 Gemini CLI 的读取标为“未实测”。切换记录从这个版本开始积累，更早的用量可能显示为“开始记录之前”。
- 统计只能读到工具自己保留的记录；Claude Code 和 Gemini CLI 默认只保留 30 天。
