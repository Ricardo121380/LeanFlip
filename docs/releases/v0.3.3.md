LeanFlip v0.3.3 新增额度查询：Codex 官方登录的限额窗口和 credits、sub2api 与 NewAPI 中转站的余额，显示在首页、统计页、Codex 账号页和托盘里。通用配置也补上了各 Agent 已核实的常用设置。

## 额度来源

- Codex 官方登录：读取 Codex 写在本机会话记录里的限额窗口和 credits，不联网。窗口按实际长度标注（比如 Pro 套餐只有周窗口），数据对应最后一次请求的时间。
- Codex 托管账号：可以联网查询当前用量，只在点刷新时请求，同一账号一分钟内最多一次；需要重新登录的账号会提示原因。
- 中转站：支持 sub2api 和 NewAPI。用卡片已有的 Key 识别平台并查询余额，只请求这张卡自己的地址，不跟随重定向，不另外保存凭据。sub2api 的总额度、5 小时 / 1 天 / 7 天窗口、订阅日周月限额和钱包余额，以及 NewAPI 的令牌额度和账户余额（站点允许时）都能显示；NewAPI 的换算比例可以按站点修改。
- 几张卡共用同一个地址和 Key 时只算一个来源，只查一次。

## 显示位置

- 首页：每个工具的当前供应商后面显示进度条和额度，展开其他供应商时它们也带上额度；没设置过的中转卡，鼠标移到那一行时可以点“查询额度”。
- 统计页：默认打开新的“额度”标签，需要注意的放在最上面，再按订阅窗口和中转余额分组；“用量记录”改为第二个标签，只在打开时读取会话记录。
- Codex 账号页：每个托管账号显示窗口、credits、数据来源和时间。
- 托盘：每个供应商后面带上额度，并新增“刷新额度”。设置里可以打开“在状态栏显示额度”，在菜单栏图标旁显示最紧张的一项，默认关闭。
- 中转卡可以设为每 15 分钟或每小时自动刷新；站点出错时也要等满一个间隔才再试。

## 通用配置

- 修正 Codex 无效的数据存储开关，以及 Claude Code 压缩窗口、输出上限的校验和权限模式、缓存覆盖的提示；补充上下文、压缩、审批、沙箱等快捷设置。
- 新增 Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes、Pi、MCode 已核实的常用设置，和 JSON / TOML 草稿双向同步。
- OpenCode 按配置文件结构区分新旧版本，更新检查统一写入 `notify`。未识别的值、没改动的旧值和其他模型保持原样，重置只删除对应字段。
- 数值在写入文件前再校验一次。各 Agent 的支持范围和核对的上游版本见 [configuration-shortcuts.md](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.3/docs/engineering/configuration-shortcuts.md)；命令行、项目和模型级别的覆盖仍可能影响实际生效。

完成 357 项 Rust 测试、217 项前端测试、TypeScript 类型检查和 Clippy。中转站接口按 sub2api 与 NewAPI 的源码核对格式，并用本机模拟服务器测试识别、查询、失败和自动刷新；Codex 本机记录和托管账号联网查询用作者的真实账号验证过。首页、统计页、Codex 账号页、供应商编辑器和设置用演示数据检查过；托盘菜单和菜单栏文字由单元测试覆盖。通用配置在临时 HOME 里实际写入并重新解析各 Agent 的原生配置文件，没有做在线模型请求。

## 升级

从 0.3.2 升级时，退出 App 后覆盖安装即可；供应商、账号和客户端配置保持原样，额度缓存会在首次查询后写入 `~/.leanflip/quota-cache.json`。

- npm：`npm install -g leanflip@0.3.3`。通过 npm 安装器管理桌面 App 的用户，退出 App 后执行 `leanflip-app install --replace`；自定义安装目录时继续使用原来的 `--app-dir`。
- Homebrew：`brew update`，再升级已安装的 `ricardo121380/leanflip/leanflip` 或 `ricardo121380/leanflip/leanflip-app` Cask。
- 下载附件：macOS Apple Silicon 的 `.dmg` 与 CLI `.tar.gz`，以及 Linux x86_64 的 `.deb` 与 CLI `.tar.gz`。SHA256 校验值见 `SHA256SUMS`。

macOS App 和 CLI 仍未做 Apple Developer ID 签名与公证；首次运行说明见 [README](https://github.com/Ricardo121380/LeanFlip/blob/v0.3.3/README.md#安装)。
